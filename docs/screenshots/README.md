# Screenshots

Здесь подготовлено место для реальных снимков приложения. Макеты и тестовые
заглушки не выдаются за работающий UI.

| Файл | Что показать |
| --- | --- |
| `map.png` | OSM, кластер, GPS accuracy, polygon и polyline |
| `object.png` | Название, расстояние, accuracy и разрешённый Check-in |
| `current-route.png` | Активный обход, длительность, точки, расстояние и визиты |
| `sync.png` | Счётчики, очередь, retry или диалог конфликта с версиями |

Снимайте на одном Android device/emulator в портретной ориентации. Используйте
демонстрационные объекты, без персональных данных. Для воспроизводимого Check-in
в эмуляторе установите координаты выбранного demo-объекта.

Команды выполняются из корня репозитория:

```sh
adb shell screencap -p /sdcard/field-inspector.png
adb pull /sdcard/field-inspector.png docs/screenshots/map.png
```

Повторите для остальных экранов с соответствующими именами. После добавления PNG
замените ячейки-заглушки в разделе Screenshots корневого README на изображения.
Для Map укажите путь `docs/screenshots/map.png` относительно корневого README
и альтернативный текст `Map`. Пока файл не создан, ссылку на изображение не добавляйте.
