# Снимки экранов

Здесь подготовлено место для реальных снимков приложения. Макеты и тестовые
заглушки не выдаются за работающий интерфейс.

| Файл | Что показать |
| --- | --- |
| map.png | OSM, кластер, точность GPS, полигон и линия маршрута |
| object.png | Название, расстояние, точность и доступная отметка о посещении |
| current-route.png | Активный обход, длительность, точки, расстояние и посещения |
| sync.png | Счётчики, очередь, повтор или диалог конфликта с версиями |

Снимайте на одном устройстве или эмуляторе Android в портретной ориентации.
Используйте демонстрационные объекты без персональных данных. Для воспроизводимой
отметки в эмуляторе задайте координаты выбранного учебного объекта.

Команды выполняются из корня репозитория:

~~~sh
adb shell screencap -p /sdcard/field-inspector.png
adb pull /sdcard/field-inspector.png docs/screenshots/map.png
~~~

Повторите для остальных экранов с соответствующими именами. После добавления PNG
замените заглушки в разделе «Снимки экранов» корневого README изображениями.
Для карты укажите путь docs/screenshots/map.png относительно корневого README
и альтернативный текст «Карта». Пока файл не создан, ссылку на изображение не добавляйте.
