# Снимки экранов

Снимки приложения «Полевой инспектор» на Android в тёмной теме.
Значения отражают состояние приложения на момент съёмки.

## Карта

![Карта](map.png)

Карта OpenStreetMap с посещёнными объектами, значками приоритета и фиолетовой
линией записанного маршрута. Сверху показаны точность текущей позиции и легенда
статусов; по краям расположены кнопки масштаба, позиционирования и перехода к обходу.

## Технический объект

![Технический объект](object.png)

Карточка учебного объекта «Тепловой пункт № 1»: адрес, статус «Посещён», высокий
приоритет и координаты. Показаны точность геолокации и расстояние до объекта.
Кнопка «Отметиться» недоступна, поскольку телефон находится за пределами радиуса
50 м. Кнопка «Показать на карте» открывает расположение объекта.

## Текущий обход

![Текущий обход](current-route.png)

Итоги завершённого обхода: продолжительность 00:40:32, 244 GPS-точки,
примерное расстояние 3139,1 м и один посещённый объект. Запись маршрута остановлена;
доступна кнопка начала нового обхода. Ниже описана работа фоновой записи на Android.

## Синхронизация

![Синхронизация](sync.png)

Диагностика показывает время последней успешной синхронизации и счётчики операций. Доступны ручной запуск синхронизации и повтор ошибочных операций;
ниже начинается список очереди.
