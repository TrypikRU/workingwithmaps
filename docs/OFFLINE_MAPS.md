# Offline maps

Команды выполняются из корня репозитория.

## Offline maps: отдельное хранилище тайлов

**Offline business data и offline map tiles — разные механизмы.** Объекты, обходы,
визиты, GPS-точки и sync_queue продолжают работать через существующие Riverpod →
repository → Drift и единый SyncEngine. Их схема, правила конфликтов и background
sync не менялись. Наличие карты не требуется для сохранения Check-in или маршрута.

Кнопка **Offline-карта** в AppBar карты открывает фиксированный регион:
Сыктывкар, ЖД вокзал / Коммунистическая, 88, bbox `[50.786, 61.654, 50.807, 61.665]`.
MVP содержит **40 тайлов** на zoom **13–16**. После загрузки кнопка камеры
**Offline-регион** вписывает эту область. Полигоны, маркеры, GPS и маршрут остаются
обычными независимыми слоями карты.

Ориентир — [Коммунистическая, 88](https://yandex.com/maps/19/syktyvkar/house/YUkYcQ5kTEwGQFhrfXp0eHxkbA==/)
(61.659078, 50.794591). Все пять учебных объектов находятся внутри региона.
Идентификатор пакета — `syktyvkar-railway-v1`. Старый пакет другого региона
не принимается: подготовьте новый MBTiles для указанной области, повторно
запустите `prepare_pack.py` и нажмите «Скачать регион». Готовые реальные тайлы
по-прежнему не входят в репозиторий.

### Подготовка и загрузка

Публичный `tile.openstreetmap.org` **запрещает prefetch/bulk download для offline**,
даже если область небольшая. Приложение не использует этот сервер для подготовки
пакетов. Политика: https://operations.osmfoundation.org/policies/tiles/

Нужен законно полученный **raster MBTiles с PNG 256×256**, содержащий весь bbox
на zoom 13–16: результат собственного renderer или провайдер, явно разрешающий
offline-использование и распространение тайлов. OSM data license сама по себе не
даёт разрешения скачивать тайлы произвольного провайдера. Не экспортируйте область
из публичного OSM XYZ через стороннюю программу для обхода этих ограничений.
Vector/PBF MBTiles и JPEG этим MVP не поддерживаются. Реальные картографические
тайлы в репозиторий не включены; тестовые PNG используются только в тестах.

Python 3, без дополнительных библиотек:

```powershell
python tools/offline_maps/prepare_pack.py C:/maps/allowed-raster.mbtiles `
  --rights-confirmed `
  --attribution "© OpenStreetMap contributors; картография: ваш renderer"
python -m http.server 8090 --bind 0.0.0.0 --directory tools/offline_maps/output
```

Утилита читает MBTiles только для фиксированных координат, преобразует TMS row в
XYZ (или читает явный metadata.scheme=xyz), проверяет полноту и формирует
`tools/offline_maps/output/field-region.json`. Сетевых запросов в утилите нет.
Флаг rights-confirmed означает, что вы проверили права источника; он не заменяет
лицензию. Укажите все требуемые текстовые credits владельца стиля/данных.
Сервер публикует только каталог готовых пакетов, не весь репозиторий.

В Android Emulator URL по умолчанию: `http://10.0.2.2:8090/field-region.json`.
На карте нажмите Offline-карта → Скачать регион. Для своего сервера:

```powershell
flutter run --dart-define=OFFLINE_MAP_PACK_URL=https://maps.example.org/field-region.json
```

Для физического устройства используйте HTTPS-сервер или `adb reverse tcp:8090 tcp:8090` вместе с URL `http://127.0.0.1:8090/field-region.json`.
HTTP предназначен для локального debug-стенда; для release используйте HTTPS.
Пакет загружается одним GET, без redirect и query-параметров. Это отдельный
статический сервер; ASP.NET backend для бизнес-синхронизации не менялся.

### Как выбирается источник

`OfflineFirstTileProvider` сначала ищет точный z/x/y в установленном пакете.
Если тайл есть, он отображается без HTTP независимо от состояния сети. Если нет —
используется стандартный NetworkTileProvider flutter_map с его HTTP cache и OSM
атрибуцией. Поэтому не требуется считать наличие Wi-Fi доказательством доступа
к интернету: offline-покрытие доступно сразу. Ошибка сети вне покрытия даёт пустую
подложку, а бизнес-слои продолжают работать. Это **local-first tile fallback**,
не online-first обновление каждого скачанного тайла.

Переключатель **Только offline-тайлы** полностью отключает сетевой fallback;
он действует в текущем запуске приложения. При установленном пакете maxNativeZoom
равен 16: zoom 17–19 увеличивает сохранённые изображения, не скачивает детали.
Ниже zoom 13 и вне покрытия offline-подложка не гарантируется. Обычный online HTTP
cache может случайно содержать больше тайлов, но не считается скачанным регионом.
Кнопка **Обновить тайлы** повторяет загрузку видимого слоя после восстановления сети;
**Обновить пакет** явно заменяет сохранённый регион.

### Хранение, ограничения и восстановление

Хранилище: `getApplicationSupportDirectory()/offline_maps/region.json`, без Drift,
без sync_queue и без WorkManager. Формат `xyz-png-v1`: region, offlineAllowed,
attribution и словарь z/x/y → base64 PNG. Для 40 тайлов это простой переносимый
альтернативный контейнер; flutter_map получает PNG через MemoryImage. Полноценный
MBTiles reader в Flutter и дополнительная библиотека архивов не нужны.

Лимиты: 12 MiB загружаемого JSON, 8 MiB PNG суммарно, 256 KiB на тайл, строго
256×256 PNG, фиксированный полный набор из 40 ключей. Поток ограничивается по
фактически полученным байтам, timeout соединения 10 секунд, receive timeout
20 секунд и deadline загрузки 2 минуты. Одновременные загрузки объединяются.
Изображения последовательно декодируются и проверяются до установки. Только
готовый пакет записывается с flush во временный файл и переименовывается в активный.
При ошибке/обрыве прежний пакет сохраняется; `.tmp` после аварии не активируется.
После перезапуска активный пакет читается с диска. Докачки нет: повтор скачивает
один небольшой файл заново. Файлы исчезают при удалении приложения/очистке данных.

В памяти хранится ограниченный набор сжатых PNG; растровые изображения кэширует
Flutter. При установке/смене режима сбрасывается только TileLayer через reset
stream: MapController, markers, polygons и сохранённая polyline не пересоздаются.

### Проверка

```powershell
python -m unittest discover -s tools/offline_maps -v
flutter test test/features/map/offline_map_test.dart
flutter analyze
flutter test
```

Тесты проверяют TMS→XYZ, полноту региона, размеры, запрет OSM download URL,
установку/замену/перезапуск, сохранение старого пакета при ошибке, отсутствие сети
для локальных тайлов и online fallback только при промахе. PNG-фикстуры нейтральные,
без картографических данных. Для ручной проверки подготовьте разрешённый MBTiles,
скачайте пакет, нажмите Offline-регион, включите авиарежим и перезапустите приложение.
Тайлы области, маркеры и маршрут должны остаться; после включения сети вне покрытия
снова доступен OSM. Права и детальность реального пакета зависят от его источника.
