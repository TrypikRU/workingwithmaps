# Офлайн-карты

Команды выполняются из корня репозитория.

## Отдельное хранилище тайлов

**Локальные бизнес-данные и сохранённая подложка карты — разные механизмы.**
Объекты, обходы, посещения, GPS-точки и sync_queue работают через Riverpod,
репозитории, Drift и общий SyncEngine. Загрузка карты не меняет схему, правила
конфликтов и фоновую синхронизацию. Для отметки о посещении карта не требуется.

Кнопка **«Офлайн-карта»** в верхней панели открывает фиксированный регион:
Сыктывкар, ЖД вокзал / Коммунистическая, 88. Границы:
[50.786, 61.654, 50.807, 61.665] — запад, юг, восток, север.
В MVP **40 тайлов** при масштабе **13–16**. Кнопка **«Офлайн-регион»**
вписывает сохранённую область в экран. Полигоны, маркеры, GPS и маршрут остаются
независимыми слоями.

Ориентир — [Коммунистическая, 88](https://yandex.com/maps/19/syktyvkar/house/YUkYcQ5kTEwGQFhrfXp0eHxkbA==/)
(61.659078, 50.794591). Все пять учебных объектов находятся внутри региона.
Идентификатор пакета — syktyvkar-railway-v1. Старый пакет другого региона
не принимается: подготовьте новый MBTiles, запустите prepare_pack.py
и нажмите «Скачать регион». Реальные тайлы в репозиторий не включены.

## Подготовка и загрузка

Общедоступный tile.openstreetmap.org **запрещает предварительную и массовую
загрузку для использования без сети**, даже для небольших областей. Приложение
не использует его для подготовки пакетов.
[Политика сервера](https://operations.osmfoundation.org/policies/tiles/).

Нужен законно полученный **растровый MBTiles с PNG 256×256**, содержащий всю
область при масштабе 13–16: результат собственной отрисовки или источник,
разрешающий использование без сети и распространение тайлов. Лицензия данных
OSM сама по себе не разрешает скачивать тайлы любого поставщика. Не экспортируйте
область из публичного OSM XYZ сторонней программой для обхода ограничений.
Векторные PBF и JPEG не поддерживаются. Тестовые PNG не содержат реальной карты.

Python 3, без дополнительных библиотек:

~~~powershell
python tools/offline_maps/prepare_pack.py C:/maps/allowed-raster.mbtiles `
  --rights-confirmed `
  --attribution "© участники OpenStreetMap; картография: ваш источник"
python -m http.server 8090 --bind 0.0.0.0 --directory tools/offline_maps/output
~~~

Утилита читает только фиксированные координаты MBTiles, преобразует номер строки
TMS в XYZ (или учитывает metadata.scheme=xyz), проверяет полноту и создаёт
tools/offline_maps/output/field-region.json. Сетевых запросов нет.
Флаг --rights-confirmed подтверждает проверку прав, но не заменяет лицензию.
Укажите все требуемые сведения об авторах стиля и данных. Сервер публикует
только каталог пакетов, а не весь репозиторий.

Адрес по умолчанию для Android Emulator:
http://10.0.2.2:8090/field-region.json.
На карте нажмите «Офлайн-карта» → «Скачать регион». Для своего сервера:

~~~powershell
flutter run --dart-define=OFFLINE_MAP_PACK_URL=https://maps.example.org/field-region.json
~~~

Для устройства используйте HTTPS или adb reverse tcp:8090 tcp:8090
с адресом http://127.0.0.1:8090/field-region.json.
HTTP предназначен для локальной отладки; в выпускной сборке используйте HTTPS.
Пакет загружается одним GET без перенаправлений и параметров запроса.
Это отдельный статический сервер, независимый от ASP.NET Core API синхронизации.

## Выбор источника

OfflineFirstTileProvider сначала ищет точный z/x/y в установленном пакете.
Найденный тайл отображается без HTTP при любом состоянии сети. Иначе используется
NetworkTileProvider из flutter_map с HTTP-кэшем и указанием авторства OSM.
Наличие Wi-Fi не считается доказательством доступа к интернету.
Ошибка сети вне покрытия оставляет пустую подложку; объекты и маршрут доступны.
Сохранённые тайлы не обновляются из сети автоматически.

Переключатель **«Только сохранённая карта»** полностью запрещает обращение к сети
на время текущего запуска. При установленном пакете maxNativeZoom равен 16:
масштаб 17–19 увеличивает сохранённые изображения без загрузки новых деталей.
Ниже масштаба 13 и вне покрытия подложка без сети не гарантируется.
HTTP-кэш может содержать дополнительные тайлы, но не считается скачанным регионом.
**«Обновить карту»** повторяет загрузку видимого слоя после восстановления сети;
**«Обновить пакет»** явно заменяет сохранённый регион.

## Хранение, ограничения и восстановление

Путь: getApplicationSupportDirectory()/offline_maps/region.json.
Drift, sync_queue и WorkManager не используются.
Формат xyz-png-v1 содержит region, offlineAllowed, attribution и словарь
z/x/y → PNG в base64. Для 40 тайлов это простой переносимый контейнер;
flutter_map получает PNG через MemoryImage. Дополнительная библиотека архивов
и чтение MBTiles непосредственно в Flutter не нужны.

Лимиты: 12 МиБ JSON, 8 МиБ PNG суммарно, 256 КиБ на тайл, строго PNG 256×256
и полный набор из 40 ключей. Поток ограничивается по фактически полученным байтам.
Ожидание соединения — 10 секунд, получения данных — 20 секунд, всей загрузки —
2 минуты. Одновременные загрузки объединяются.

Изображения последовательно декодируются и проверяются до установки.
Готовый пакет записывается во временный файл с принудительной записью на диск,
затем переименовывается. При ошибке прежний пакет сохраняется; файл .tmp после
аварии не активируется. После перезапуска активный пакет читается с диска.
Докачки нет: повтор скачивает небольшой файл заново. Удаление приложения или
очистка данных удаляют и пакет.

В памяти хранится ограниченный набор сжатых PNG; декодированные изображения
кэширует Flutter. Установка и смена режима сбрасывают только TileLayer через
поток сброса. MapController, маркеры, полигоны и линия маршрута не пересоздаются.

## Проверка

~~~powershell
python -m unittest discover -s tools/offline_maps -v
flutter test test/features/map/offline_map_test.dart
flutter analyze
flutter test
~~~

Тесты проверяют TMS→XYZ, полноту и размеры, запрет загрузки пакетов с адресов OSM,
установку, замену, перезапуск, сохранение старого пакета при ошибке, отсутствие
запросов для локальных тайлов и переход к сети только при их отсутствии.
Тестовые изображения нейтральные, без картографических данных.

Для ручной проверки подготовьте разрешённый MBTiles, скачайте пакет, нажмите
«Офлайн-регион», включите авиарежим и перезапустите приложение. Тайлы региона,
маркеры и маршрут должны остаться. После включения сети вне покрытия снова
доступен OSM. Права и детализация пакета зависят от его источника.
