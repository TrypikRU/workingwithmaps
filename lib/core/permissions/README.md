# Разрешения

Геолокацией управляет `core/location/LocationController` через `LocationService`:
проверки доступа и жизненный цикл потока находятся в одном месте. Интерфейс
не вызывает Geolocator напрямую.

В AndroidManifest объявлены ACCESS_COARSE_LOCATION и ACCESS_FINE_LOCATION.
Карта принимает приблизительное местоположение и показывает фактическую точность.
Диалог разрешения открывается только кнопкой «Разрешить». Состояние deniedForever
требует перехода в настройки; после возвращения доступ проверяется заново.

Источник координат карты работает только при открытом приложении. Отдельный
сервис записи обхода использует FOREGROUND_SERVICE и FOREGROUND_SERVICE_LOCATION
и запускается из видимой Activity. Для него требуется точное местоположение.
POST_NOTIFICATIONS запрашивается для уведомления о записи маршрута.
ACCESS_BACKGROUND_LOCATION не требуется для продолжения уже запущенного сервиса.

Подробности: [слой геолокации](../location/README.md) и
[запись маршрута средствами Android](../../features/tracking/README.md).
Другие виды разрешений можно добавлять по мере необходимости.
