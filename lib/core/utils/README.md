# Общие функции

AppLogger в `app_logger.dart` записывает структурированные события SyncEngine
и фоновых обработчиков. По умолчанию используется `dart:developer` с именем
«Полевой инспектор»; поле `sink` позволяет заменить получателя записей.

В журнал не передаются координаты, данные запросов и HTTP-заголовки.
Исключение получателя перехватывается и не прерывает бизнес-операцию.
Логика конкретного функционального модуля остаётся внутри него.
